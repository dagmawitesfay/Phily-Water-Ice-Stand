# Philly Water Ice Stand

A fully responsive landing page for a fictional Philadelphia water ice stand, styled around a bright, nostalgic summer brand identity. The project combines rich typography, bold color sections, and a classic South Philly storefront aesthetic.

## Overview

This site showcases a local water-ice brand called "Two Street Water Ice" and highlights:

- Signature flavors and menu board
- Seasonal opening information
- Cup size pricing
- Stand location and contact details
- Mobile-friendly responsive layout

The project is built with plain HTML and CSS, with no framework or build tooling required.

## Features

- Responsive single-page layout
- Hero section with storefront imagery and branding
- Flavor highlight cards for popular menu options
- Menu pricing section with a clean card-based design
- Location/contact section for the stand
- Footer with business details and store hours
- Custom typography and color palette inspired by summer, citrus, and classic Philly branding

## Run Locally

Because this is a static website, you can open it directly in a browser:

1. Clone the repository.
2. Open `index.html` in your preferred browser.

Optional local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Design Notes

The page uses a warm, playful brand aesthetic designed to feel like a summer neighborhood staple. Key visual cues include:

- Bright confidence-inspired color blocks
- Bold headings and friendly, casual copy
- Clean card layouts for product and info sections
- Bold contrast between background colors and highlight text
